Object voxelizer — signs, props, tall trees

      
Capture any rectangular group of map cells. It becomes one exact graphic pattern, so a 2×2 or taller tree stays connected. The tool cuts away edge-connected background like the Gen 1 sign treatment; click pixels to correct the mask. Red pixels are removed; visible pixels become a 3D voxel prism.

      

      
      
For a sign or any one 16×16 cell, select it and use the first button. For trees and connected scenery, set both rectangle corners instead.

Fix a house — capture its full tile drawing

      
A house is not repaired by painting four tiles “roof.” Capture the entire visible house rectangle; PotatoVoxel will match that exact tile layout everywhere it appears and build a roof plus façade from its own art.
